
CampusCare - Campus Complaint & Issue Management System

CampusCare is a web-based management system built to streamline the process of reporting, assigning, and resolving campus-related issues and complaints.
It bridges communication between students/staff, assigned maintenance workers, and campus administrators.


Key Features
Role-Based Access Control: Tailored dashboards and workflows for Users (Students/Faculty), Workers, and Administrators.

Complaint Tracking: End-to-end status tracking from issue submission to resolution.

Admin Dashboard: Centralized panel to review incoming complaints, allocate tasks to staff, and monitor resolution timelines.

Worker Dashboard: Interface for service workers to receive assignments and update job statuses.


Tech Stack:
Backend: Java, Spring Boot, Spring Data JPA

Frontend: HTML5, CSS3, Thymeleaf templates

Database: MySQL

Build Tool: Maven
